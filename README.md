# נגריית אלון

עמוד נחיתה לנגר עצמאי מפרדס חנה, עם טופס יצירת קשר המחובר לאוטומציה ב־n8n.

## מה יש כאן

| קובץ | תפקיד |
|---|---|
| `index.html` | העמוד כולו. עברית, RTL, נייד קודם |
| `style.css` | העיצוב. משפחת גופנים אחת, ללא ספריות |
| `n8n/negariyat-alon-workflow.js` | הוורקפלואו, כקוד SDK של n8n |
| `prompts/nano-banana-furniture.md` | הפרומפטים שמהם נוצרו תמונות הרהיטים |

## האתר

שני קבצים, ללא כלי בנייה, ללא npm, ללא ספריות חיצוניות. ה־JavaScript היחיד
בעמוד הוא ולידציה של הטופס ושליחה ל־webhook.

- טיפוגרפיה: Tinos מ־Google Fonts
- תמונות: מוגשות מ־Cloudinary עם `f_auto,q_auto` ו־`srcset`
- הצבעים: ירוק זית לכפתורים, ברונזה לקווים בלבד

התמונות נוצרו ב־AI כפתרון ביניים, לבקשת הלקוח, עד שיהיו צילומים אמיתיים.
הן מתויגות ב־Cloudinary בתגית `temporary`.

## הזרימה

```
טופס באתר
   ↓  POST
Webhook (n8n)
   ↓
נרמול השדות
   ↓
שמירת שורה ב־Google Sheets
   ↓
   ├─→ מייל התראה לבעל העסק
   └─→ מייל אישור לפונה
```

## הרצה מקומית

```bash
python3 -m http.server 8777
# ואז http://localhost:8777
```

## מה עוד לא הושלם

- `allowedOrigins` בוובהוק פתוח לכוכבית לצורכי פיתוח. לפני עלייה לאוויר
  יש להחליף בדומיין הספציפי
- הטלפון והמייל בעמוד הם מצייני מקום ולא פרטים אמיתיים
- כתובת בעל העסק בוורקפלואו היא כתובת בדיקה
- אין לוגו גרפי, רק שם בטיפוגרפיה
